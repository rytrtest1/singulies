# Finale — quatre finalistes

Issus du tour 2 (décompte dans `t2-votes.md`). Ce ne sont plus des idées isolées mais des **sites complets**, chacun avec un champion qui le défend. Socle commun que tous gardent : fournée (I, rareté vraie, n° tapé), paiement Stripe immédiat (adresse et email chez Stripe), vraie preuve humaine (5–8 s de mains, photo d'une vraie feuille), le site 3D jamais sur le chemin du paiement, pages `/v/<id>` par vidéo pour mesurer (B).

1. **« La feuille qui attend »** — champion : Théo. A + aiguillage C juste après l'acrostiche + D en option du « pour offrir ». Le 3D = réception du destinataire (D) + entrée secondaire.
2. **« Tire d'abord »** — champion : Malik. F + A : on entre par le geste de la vidéo (le paquet tire une question douce), puis le prénom, l'acrostiche, le prix.
3. **« La cérémonie »** — champion : Victor. A + C, puis **après paiement** le site 3D devient le rituel de l'acheteur (sa question, sa feuille, son enveloppe, le cachet).
4. **« À qui j'écris ? »** — championne : Céleste. Le site entre par le cadeau (C + D) : « à qui j'écris ? », le lien où l'autre répond en option forte, « pour moi » en second.

## Plaidoyer 4 — « À qui j'écris ? » (Céleste)
- **Écran 1** : 6 s de vraies mains ; « à qui j'écris ? » + champ ; « fournée de noël · 37 places sur 100 · 64 € port compris · arrive avant le 20 décembre » ; l'acrostiche se forme avec lignes vides (« ces lignes, je les tape à la main ») + photo d'une vraie feuille.
- **Écran 2** : « c'est moi » · « je l'offre » (« c'est moi » présélectionné depuis /v/<id>).
- **Pour moi** : carte tirée parmi 12 questions douces (passable) → Stripe → rituel court (sautable) → « tu es le n° 63 ».
- **Pour offrir** : « chez lui » / « je lui remets en main » → mot → « qui répond ? » **moi** (défaut, 3 questions au choix) / **lui** (lien, thème de secours obligatoire) → Stripe → **le bon tout de suite** (carte WhatsApp + PDF imprimable « eternel t'écrit · arrive avant le 20 décembre »).
- **Destinataire (voie « lui »)** : vignette avec visage + **voix** d'Eternel (10 s) ; champ 3D, son prénom s'allume, 3 questions douces ; « garde ta réponse, écris quand même » ; repli J+7 sans relance.
- Réponses : lien envoyé par l'acheteur depuis son numéro ; bon immédiat ; défaut = « moi » ; thème de secours = rien ne bloque ; plus de date garantie → fournées datées.
- Effort ≈ 6 j (+2 j serveur après test ; voie « lui » d'abord à la main + EmailJS). Maxence : 6 s de mains, 10 s voix/visage, 3 photos, 12 questions douces, prix, fournées, Stripe.
- Tort si : < 40 % « je l'offre » sur 50 commandes ; < 60 % de réponses voie « lui » sur 20 liens.
- Honnête : « La feuille qui attend » sert mieux « le sien » ; Victor fait un meilleur rituel (elle le reprend).

## Plaidoyer 1 — « La feuille qui attend » (Théo)
- **Écran 1** (sans défiler) : 6 s de vraies mains + « @e.t.ernel » ; « je t'écris un poème à la machine. » ; « écris un prénom. » + champ ; « fournée d'octobre · 23 places sur 60 · envoi le 24 · 64 €, port compris ».
- **Écran 2** : LEA tapé → colonne lettre à lettre + lignes pointillées ; « ces lignes n'existent pas encore. je les tape pour toi, à partir de ta réponse. » ; photo réelle feuille + enveloppe + cachet ; **pour moi · pour l'offrir**.
- **Pour moi** : question douce (« une autre », « garde ta réponse pour toi ») → récap (LEA · question · n° 37) → payer 64 € (Stripe : adresse + email).
- **Pour offrir** : un mot + fournée datée d'envoi (« je poste le 15 décembre, chez elle vers le 18 ») → « je choisis sa question » (défaut) / « elle répondra » (D) / « c'est pour ce soir » (bon) → Stripe (adresse du destinataire).
- **Après** : « c'est noté. LEA, n° 37 … je tape le 24. » + image 9:16 « eternel m'écrit » ou le bon ; « entrer dans le monde d'eternel » (3D) en dernier.
- Réponses : IA → rien n'est généré, le vide est la promesse, mains au-dessus du champ ; capture = pub signée ; D jamais bloquant, page statique + EmailJS, liens envoyés à la main.
- Effort ≈ 8 j. Tort si : < 2 % de ceux qui tapent un prénom paient ; > 60 % des paiements « pour l'offrir » (→ Céleste).
- Honnête : Céleste meilleure si le cadeau domine, Victor plus d'émotion après, Malik plus proche du geste de la vidéo.

## Plaidoyer 2 — « Tire d'abord » (Malik)
- **Écran 1** : ETERNEL ; 6 s de mains qui tirent une carte puis tapent ; le paquet : « je tire une carte pour toi. » / « touche le paquet. » ; « un prénom, un poème, tapé à la machine · 64 €, envoi compris · fournée du 24 octobre : 37 places » + « c'est pour offrir → ».
- 1re carte = 5 questions douces seulement : n° 21 « quel moment à deux voudrais-tu faire durer toujours ? », n° 41 « as-tu aimé chez l'autre un défaut comme une qualité ? », n° 70 « qui reste pour toi incomparable aux autres ? », n° 69 « crains-tu d'user les mots à force de les dire ? », n° 16 « réfléchir ou dire ? ».
- **Pour moi** : réponse en une ligne / une autre (2×) / garde ta réponse / passer → prénom + acrostiche + 3 photos réelles → récap, bouton « le recevoir » → Stripe → « c'est noté. n° 63. » + image 9:16 ; 3D discret.
- **Pour offrir** : son prénom → « tire sa carte » → « je connais sa réponse » / « sur la question seule » / « qu'il réponde » (D) → mot → fournée datée → Stripe → bon du soir.
- Effort ≈ 5,5 j. Tort si : F convertit > 20 % de moins que A (A/B 500 visites) ; > 35 % quittent sur la carte.
- Honnête : A plus simple et plus sûre pour vendre, Céleste meilleure pour le cadeau, Victor plus belle.

## Plaidoyer 3 — « La cérémonie » (Victor)
- **Écran 1** : 6 s de mains ; « je t'écris ton prénom, à la machine. » + champ ; « fournée n° 7 · 100 poèmes · 41 restent » ; « 64 €, port compris · posté avant le 30 octobre » ; photo réelle en dessous ; acrostiche + lignes vides + « ces lignes, je les tape pour toi. » ; **pour moi · pour l'offrir**.
- **Pour moi** (3 écrans) : prénom → « n° 59 de la fournée 7 · posté avant le 30/10 · 64 € » « le recevoir » → Stripe. **Aucune question avant de payer.**
- **Pour offrir** (4 écrans) : son prénom → mot + fournée datée → chez lui / chez moi / un bon pour ce soir (+ option D) → Stripe.
- **La cérémonie** (5 écrans, ≈ 75 s, facultative) : 1) champ de prénoms, ses lettres volent (8 s) ; 2) le paquet tire ta question (réponse / garde-la / une autre) ; 3) la feuille, l'acrostiche descend, le n° se tape ; 4) l'enveloppe « à LEA », le cachet ; 5) image 9:16 « eternel m'écrit ». Lien de la cérémonie dans l'email, valable à vie ; version simple automatique ; préchargée pendant Stripe ; sans réponse → repli 48 h sur la question.
- Effort ≈ 8 j (D plus tard, +3 j). Tort si : < 50 % des acheteurs atteignent l'enveloppe ; < 10 % partagent l'image et < 5 % des commandes en viennent.
- Honnête : Théo émerveille mieux le destinataire (il lui vole un QR de réception au 2e mois) ; Malik restitue mieux le geste de la vidéo.
